# Учебные задания

Храните паспорта заданий по классам: `grade-5/`, затем по мере наполнения `grade-7/`, `grade-10/`. Интерактивные страницы лежат отдельно в `html/`; этот раздел предназначен для условий, методики, ответов и источников.

Начните с [шаблона](templates/task-template.md). Готовый пример: [уравнение для 5 класса](grade-5/equations.md).

Для каждого задания нужны: класс, тема, язык, цель, время, уровень, условие, ответ с решением и критерии. Для STEM дополнительно — единицы, источники, даты и ограничения модели. Ответы в публичном репозитории доступны всем; материалы рассчитаны на тренировку, а не на закрытую контрольную работу.
