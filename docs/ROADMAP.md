## Перед использованием нового материала

Проверить математические ответы, все относительные ссылки, ввод и сброс, доступ с клавиатуры, читаемость на проекторе, узкий экран и печать. Провести пробный запуск с отключённым интернетом. После урока записать фактическое время и затруднения учеников, не указывая их персональные данные.

Публикацию через GitHub Pages можно настроить отдельным шагом. Для локального запуска она не требуется.
