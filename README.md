# Математика в действии

Стартовый учебный проект: HTML-игры, интерактивные задания и STEM-материалы для школьных уроков математики. Репозиторий: `expert-octo-palm-tree`; исходная идея — «ойын» (игра).

## Быстрый запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Выберите задание «Уравнения: первый шаг».

Интернет, регистрация и установка зависимостей не нужны. Сохраняйте структуру папок при копировании на школьный компьютер. Ответы не отправляются на сервер и не сохраняются после перезагрузки.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная страница с каталогом готовых заданий |
| `html/equations.html` | Страница первого интерактивного задания |
| `css/styles.css` | Общие стили для экрана, проектора и печати |
| `js/equations.js` | Проверка ответа и обратная связь |
| `tasks/README.md` | Правила оформления учебных материалов |
| `tasks/grade-5/equations.md` | Цель, сценарий, ответы и критерии первого задания |
| `tasks/templates/task-template.md` | Шаблон нового задания |
| `docs/ROADMAP.md` | Очерёдность следующих файлов и критерии готовности |

## Как использовать на уроке

Первый пример рассчитан на 5–7 минут: объяснение инструкции, самостоятельное решение, проверка и обсуждение способа решения. Можно работать индивидуально, в парах или у доски. Для печатного варианта откройте страницу задания и нажмите Ctrl+P (на Mac — Cmd+P).

## Как расширять

1. Скопируйте шаблон из `tasks/templates/` в папку нужного класса и заполните паспорт задания.
2. Создайте страницу в `html/`, подключив `../css/styles.css`.
3. При необходимости добавьте отдельный скрипт в `js/` и подключите его с `defer`.
4. Добавьте ссылку в `index.html` только после проверки задания.
5. Проверьте математику, пустой и неверный ответы, клавиатуру, узкий экран, печать и запуск без интернета.

Используйте относительные ссылки и понятные имена файлов латиницей, например `standard-form.html`. Для работы через открытый файл избегайте `fetch`, JavaScript-модулей и внешних CDN. Для русской и казахской версий создавайте отдельные страницы с корректным атрибутом `lang`.

В STEM-заданиях указывайте источник, дату и единицы измерения данных. Условные учебные числа явно помечайте как модельные. Не добавляйте персональные данные учеников в публичный репозиторий.
